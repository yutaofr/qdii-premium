### 9.2 经济定义（固定口径）

设同合约、同口径的 `b(s) = F(s)/I(s) − 1`，`R_F = F(t)/F(c)`、`R_I = I(t)/I(c)`：

```text
R_F / R_I − 1 = (b(t) − b(c)) / (1 + b(c))          期货代理的相对收益误差
R_F − R_I     = R_I · (b(t) − b(c)) / (1 + b(c))    收益率差
```

"基差漂移" `b(t) − b(c)`、收益率差、净值相对误差是三个不同的量，分字段报告，不直接画等号。
亚洲时点的 `I(t)` 若指经济公允价值，需要独立定义的基准；官方指数在亚洲时段停在昨收，不能当作正在更新的经济价值。

生产用结算 `S(c)` 作分母，还多出锚点差异：

```text
[F(t)/S(c)] / [I(t)/I(c)] = [(1 + b(t)) / (1 + b(c))] · [F(c)/S(c)]
```

这只是分解，不说明任何一项已知。研究用的期货五分钟线收盘、生产用的买卖价中点、官方结算、供应商昨结算是四种定义。
CME 对纳指期货主力合约列出 14:59:30—15:00 CT 的成交 VWAP 及无成交时的回退规则，其他月份另有规则，
不能概括为"每份合约的结算都是某一时刻的成交价"；这些规则也不证明新浪字段的日期与数值已获官方确认。

**方向算例（仅验证符号）：** `b(c) = 0.01`、`b(t) = 0.0095`，基差收窄 5bp → 期货代理净值相对偏低约 4.9505bp；
若真实溢价为 10%，估算溢价偏高约 5.4482bp。这不说明亚洲时点存在这样的变化。
